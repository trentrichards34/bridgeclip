# Classic (orange) scene library

These are real scenes from the creator's reels in the "classic" orange look (paper #F6F5F1, ink #111, signal red, halftone shadows), de-branded: sponsor and product names are neutral placeholders (Database, Deploy, Browser Tools, agent-crew, LearnMode), hard-coded comment words became a `KEYWORD` variable, and the presenter character is just "the presenter".

Treat every file as reference code to read and adapt, not as drop-in scenes. They rely on the engine core helpers (lib.js / ui.js / presenter: `X`, `fillRR`, `text`, `E.*`, `kick`, `burst`, `wi`/`owi`, `GUY3D`, ...) and on the kits in `library/classic/kits`. Word indices (`wi(n)`) and hard-coded timestamps belong to the original scripts, so re-cue on your own words.json. Image assets are not shipped (`IMG[...]` lookups no-op when missing). The `roster()` through-object used by the solo_* files lives in a kit that is not included; read it as an example of a persistent through-object card.

How to use: read the scene that is closest to your beat, then copy the functions/techniques you need into your own `scenes/*.js` file (prefix helper names per file to avoid collisions). Do not load these files wholesale: some kit names collide with engine globals (`PRESENTER_DOCK`, `SPIN`, `codeChip`, `win`/`arms`/`expr`), and `owi()` (an old voice clock) does not exist in the engine, use `wi()` / `wordAt()`. `GUY3D` is an alias of `PRESENTER`, `baFlow`/`baGlow`/`baImpact`/`baPuff`/`baDotShadow`/`baTypeSeg` exist in the engine as `flow`/`glow`/`impact`/`puff`/`dotShadow`/`typeSeg`.

## Example props (library/classic/props)

Finished props that used to ship in the engine's mechanics kit. They are STUDIED EXAMPLES: each file's header says what idea it
visualised, the motion techniques inside (physics, overshoot values, idle life) and: don't reuse as-is, build THIS script's own prop
with these techniques (guides/patterns.md). Not loaded by the engine; `test/classic-showcase` loads them to show them working.
They use the engine primitives in `engines/classic/kits/mechanics.js` (and its private helpers `_mono`, `_MG`, `_mA`, `_mctx`).

| file | idea | techniques worth stealing |
|---|---|---|
| props/gauge.js | effort / risk pushed past the limit, then the limit breaks | under-damped needle (springTo z 0.28), strain jitter + seeded sparks, label pop, needle drop + dangling pendulum, growing glass cracks |
| props/alarmClock.js | time pressure, a routine accelerating | minute hand on an integrated speed curve (phaseAt) + blur fan, per-tick overshoot of the second hand, bell ringing shake |
| props/stackTower.js (+ towerBlock) | load piling up until it collapses | quadratic drop + squash + dust, sway that grows with height, landing jolts up the column, staggered gravity topple |
| props/clothesline.js (+ idBadge) | one person wearing many hats | line that sags per landing, bungee lanyard + pendulum, neighbour jolts, presenter clone as badge photo, ghost / snap |
| props/powerStrip.js | add-ons plugging into one base | swing-in on a cable, hover, cock back, inQuart slam, LED sputter table, power flowing up the cable |
| props/leverSwitch.js | a decision made physical | springTo flip with overshoot, label pop, sparks, lifted knob shadow |

## Illustrated examples (library/classic/illustrated): drawing REAL things like real life

Finished, de-branded drawers of real-world subjects (studied from two reels that drew a fast-food chain and a furniture megastore
"like the real thing"). Built ONLY on the engine's drawing primitives `engines/classic/kits/illustrate.js` (isometric boxes/roofs/slabs,
3-tone shading, gradients + gloss, lit windows, cars, trees, tiny people, pole signs, die-cut stickers, the playing-reel clock).
Method, per-category detail lists and checklist: **`guides/illustration.md`**. Study them for the level of detail, then draw THIS
script's subject with the primitives: `reel craft` counts these drawer names as stock. No real logos or wordmarks are shipped.
Each takes natural coordinates with a bounds box (`*_BOX`) so `placeArt()` / `sticker()` can place it by its bottom-centre.
